# استوديو سوبرنوفا للفيديو 🚀

### استوديو فيديو متعدد المحركات من SupernovaSolutionsHQ

منتج كامل قابل للاستضافة الذاتية: حسابات، مساحة عمل، سجل أعمال، تنزيلات حقيقية،
روابط مشاركة ولوحة تحليلات. ثمانية محركات، ٢٤ مقطعًا مولّدًا برمجيًا، وست لغات.

**الإصدار 3.1 — «فيديو حقيقي مع بديل صادق»**: تُرسَل النصوص إلى fal.ai أو Replicate
عند توفّر مفتاح، ويعمل وضع العرض كبديل تلقائي عند غياب المفتاح أو فشل المزوّد.

---

## ⚡ ما الذي يولّد الفيديو؟

| الوضع     | متى يُستخدم                                                 | الناتج                                              |
| --------- | ----------------------------------------------------------- | --------------------------------------------------- |
| **مباشر** | عند إعداد مفتاح (`FAL_KEY` أو `REPLICATE_API_TOKEN`)        | مخرجات نموذج حقيقية تُنزَّل إلى خادمك ثم تُبَثّ منه |
| **عرض**   | بلا مفتاح، أو `RENDER_PROVIDER=demo`، أو رفض المزوّد للمهمة | واحد من ٢٤ مقطعًا داخل المستودع، موسوم بوضوح كعرض   |

| المجال                          | حقيقي؟         | المكان                                     |
| ------------------------------- | -------------- | ------------------------------------------ |
| التوليد بمفتاح                  | ✅             | `lib/render/providers/{fal,replicate}.ts`  |
| التوليد بلا مفتاح               | ⚠️ مقاطع جاهزة | `lib/render/providers/demo.ts`             |
| الحسابات (GitHub أو ضيف)        | ✅             | Auth.js v5 — `lib/auth.ts`                 |
| سجل التوليد                     | ✅             | قاعدة SQLite — جدول `renders`              |
| تخزين الفيديو وبثّه             | ✅             | `lib/media/{store,serve}.ts` و `MEDIA_DIR` |
| التنزيلات                       | ✅             | `app/api/download/[id]`                    |
| روابط المشاركة وبطاقات المعاينة | ✅             | `app/api/share/[id]` و `app/s/[slug]`      |
| التحليلات                       | ✅             | تجميع SQL في `lib/analytics.ts`            |

## 🔑 تفعيل توليد الفيديو الحقيقي (٥ دقائق)

1. أنشئ حسابًا على <https://fal.ai> — تحصل على **١٠ دولارات رصيد مجاني** عند التسجيل.
2. أنشئ مفتاحًا من <https://fal.ai/dashboard/keys>.
3. أضفه إلى `.env.local`:

   ```bash
   RENDER_PROVIDER=auto
   FAL_KEY=your-key-here
   ```

4. أعد تشغيل الخادم وتأكّد: `curl -s localhost:3000/api/render`.

**التكلفة:** نحو **٠٫٠٥ دولار لكل ثانية** بدقة 480p (LTX-2 Fast أو Wan 2.5)، أي
**≈٠٫٢٥ دولار لمقطع من ٥ ثوانٍ**، والرصيد المجاني يكفي نحو **٢٠–١٠٠ مقطع**. تحكّم في
التكلفة عبر `VIDEO_DURATION_SECONDS`.

**بديل:** Replicate بمفتاح `REPLICATE_API_TOKEN` (نحو ٠٫٠٩ دولار/ثانية، كتالوج أوسع).
**بلا تكلفة:** `RENDER_PROVIDER=demo` — وهو أيضًا البديل التلقائي عند فشل المزوّد،
وتُبلِّغ الاستجابة عن ذلك بـ `"fallback": true`.

## ✨ ما يعمل اليوم

- **الاستوديو** (`/studio`): ثمانية محركات، تتبع مباشر للتقدم، إلغاء، تنزيل ومشاركة،
  وشريط بأحدث الأعمال يتحدّث تلقائيًا.
- **الحسابات**: تسجيل عبر GitHub أو الدخول كضيف بنقرة واحدة.
- **السجل** (`/history`): بحث في النصوص، تصفية حسب المحرك، وتقسيم إلى صفحات.
- **التنزيلات**: `/api/download/:id` يبثّ الملف باسم واضح، ولا يصل إليه إلا المالك أو
  من يملك رابط مشاركة.
- **المشاركة**: معرّفات قصيرة غير قابلة للتخمين، صفحة عامة لكل عمل، وبيانات
  Open Graph خاصة بكل مقطع.
- **التحليلات** (`/dashboard`): حجم التوليد خلال ١٤ يومًا، توزيع المحركات، نسبة النجاح،
  متوسط الزمن، التنزيلات والمشاركات.
- **التجربة**: ست لغات (بما فيها العربية من اليمين إلى اليسار)، شريط تنقّل سفلي على
  الهاتف، احترام حواف الشاشة (notch)، حركات متتالية تُعطَّل مع `prefers-reduced-motion`،
  وواجهة كاملة بلوحة المفاتيح.

## 🚀 البدء السريع

```bash
# Node.js ≥ 20.9 (يُفضّل 22 LTS)
git clone https://github.com/rafik336-tech/supernova-video-studio-pro.git
cd supernova-video-studio-pro
npm install

cp .env.example .env.local     # اختياري — كل القيم لها بدائل افتراضية
npm run seed                   # اختياري: بيانات تجريبية لـ ١٤ يومًا

npm run dev                    # http://localhost:3000
```

افتح `/studio` ثم **تسجيل الدخول → المتابعة كضيف**. التوليد والسجل والتنزيل والمشاركة
والتحليلات تعمل مباشرة.

### تفعيل الدخول عبر GitHub (اختياري)

1. أنشئ تطبيق OAuth من <https://github.com/settings/developers>.
2. رابط الاستدعاء: `http://localhost:3000/api/auth/callback/github`
3. أضف إلى `.env.local`:

```bash
AUTH_GITHUB_ID=your_client_id
AUTH_GITHUB_SECRET=your_client_secret
AUTH_SECRET=$(openssl rand -base64 32)
```

بدون هذين المتغيّرين لا يُسجَّل المزوّد أصلًا، وتظل صفحة الدخول تعمل بالوضع الضيف.
`AUTH_SECRET` إلزامي في الإنتاج.

## 🔌 الواجهة البرمجية

`GET /api/render` (عام، ويُبلِّغ عن المزوّد النشط) · `POST /api/render` (يتطلب جلسة) ·
`GET /api/render/:id` (المالك فقط) · `GET /api/renders` · `GET /api/media/:id` (بثّ
مباشر مع دعم Range) · `GET /api/download/:id` · `POST /api/share/:id`.
التفاصيل الكاملة في [`docs/API.md`](docs/API.md).

## 🚢 النشر

تحتاج **وحدة تخزين دائمة** لمجلد `data/` (قاعدة البيانات والمقاطع المولّدة)؛ على منصات
بلا نظام ملفات دائم يضيع السجل والفيديو.
استخدم حاوية أو خادمًا مستقلًا، أو انقل طبقة البيانات إلى Postgres أولًا
(انظر [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md#database-portability)).
قاعدة البيانات تُطبّق مخططها تلقائيًا عند أول تشغيل.

## ⚠️ حدود معروفة

- بلا مفتاح مزوّد، تكون النتائج مقاطع عرض جاهزة (موسومة بذلك).
- جودة المقاطع المولّدة تعتمد على ما يشتريه سعر كهذا (دقة 480p تقريبًا).
- الجلسات JWT بلا إلغاء فوري قبل انتهاء صلاحيتها.
- حسابات الضيف مؤقتة.
- SQLite بعقدة واحدة.
- تحديد المعدّل داخل العملية الواحدة.
