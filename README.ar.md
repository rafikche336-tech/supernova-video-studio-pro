# سوبرنوفا — استوديو الفيديو 🚀

### استوديو فيديو متعدد المحركات — من SupernovaSolutionsHQ

> **ملاحظة مهمة:** هذا الإصدار في **الوضع التجريبي**. الواجهة وواجهة البرمجة ونظام
> المهام كلها حقيقية، لكن المقاطع المعروضة **مُولّدة برمجياً داخل المشروع** وليست
> مخرجات نموذج ذكاء اصطناعي. لا يوجد أي كود استدلال (Wan 2.2 / Mochi 1 / SVD /
> OpenShorts) في هذا المستودع. لتفعيل التوليد الحقيقي، نفّذ الواجهة
> [`RenderProvider`](./lib/render/types.ts) واربطها بخدمتك — التفاصيل في
> [docs/ARCHITECTURE.md](./docs/ARCHITECTURE.md).

## التشغيل السريع

```bash
# يتطلب Node.js 20.9 أو أحدث
npm ci
npm run dev        # http://localhost:3000
```

لا حاجة إلى مفاتيح API ولا إلى كرت رسومات: الوضع التجريبي هو الافتراضي.

## ما الذي يعمل فعلاً؟

- **ثماني بطاقات محركات** قابلة للفتح، مع نموذج إدخال لكل بطاقة، وتعمل بالكامل
  عبر لوحة المفاتيح وقارئات الشاشة.
- **دورة مهمة حقيقية**: إنشاء المهمة ← متابعة التقدّم ← النتيجة، مع الإلغاء
  وإعادة المحاولة ومعالجة الأخطاء.
- **ست لغات** (العربية · الإنجليزية · الفرنسية · الإسبانية · الألمانية · الصينية)
  مع تبديل تلقائي للاتجاه `rtl` وسمة `lang` في الصفحة.
- **حماية للواجهة البرمجية**: تحقّق من المدخلات، قائمة محركات مسموحة، حدود لطول
  الطلب والنص، وتحديد لمعدّل الطلبات لكل زائر.
- **وسائط مستضافة ذاتياً**: ستة مقاطع مدتها 3 ثوانٍ (~470 كيلوبايت) من إنشاء
  المشروع نفسه، بترخيص CC0.

## الأوامر

| الأمر                         | الوظيفة                              |
| ----------------------------- | ------------------------------------ |
| `npm run dev`                 | خادم التطوير                         |
| `npm run build` / `npm start` | بناء وتشغيل نسخة الإنتاج             |
| `npm run typecheck`           | فحص الأنواع                          |
| `npm run lint`                | ESLint (يعمل دون تدخّل، مناسب لـ CI) |
| `npm test`                    | 41 اختبار وحدة                       |
| `npm run test:integration`    | 57 فحصاً شاملاً على خادم إنتاج حقيقي |
| `npm run verify`              | الأنواع ← Lint ← الاختبارات ← البناء |

## واجهة البرمجة

```bash
curl -X POST localhost:3000/api/render \
  -H 'content-type: application/json' \
  -d '{"prompt":"لقطة سينمائية للبحر عند الغروب","engine":"wan"}'
```

المرجع الكامل: [docs/API.md](./docs/API.md).
