## Optional inference services

Video generation is **off by default**. When an operator configures a key, prompts
leave this server for one of these services, governed by their terms and privacy
policies, not by this project's licence:

| Service                            | Used for                                       | Terms                                   |
| ---------------------------------- | ---------------------------------------------- | --------------------------------------- |
| [fal.ai](https://fal.ai)           | Default live text-to-video backend (queue API) | <https://fal.ai/legal/terms-of-service> |
| [Replicate](https://replicate.com) | Alternative live backend (predictions API)     | <https://replicate.com/terms>           |

No model weights are bundled or redistributed by this repository: the app calls
hosted APIs and downloads only the resulting video files. Models served by those
platforms (e.g. LTX-Video by Lightricks, Wan by Alibaba) carry their own licences,
which the hosting platform applies — check the model card before commercial use.

`api.replicate.com` and `queue.fal.run` are contacted only from the server, and
only when a key is set.

## Fonts

No webfonts are bundled or fetched. The UI uses the platform system font stack
(`--font-sans` in `app/globals.css`), which keeps the app hermetic — no request
ever leaves the visitor's browser to a third party.

The build-time scripts (`generate-og-image.py`) use DejaVu Sans when it is
available on the machine; the generated images are covered by CC0 above.
